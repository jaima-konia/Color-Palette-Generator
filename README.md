# 🎨 Color Palette Generator

A simple and interactive **Color Palette Generator** built with **HTML, CSS, and JavaScript**.
The app generates a palette of random colors and allows users to easily copy individual HEX color codes to their clipboard.

## 🚀 Features

* Generate a random color palette
* Display HEX color codes for each color
* Click on a color to copy its HEX value
* Click the **Copy** button to copy the HEX value
* Visual feedback after successfully copying a color
* Dynamically generate and update palette elements
* Responsive and simple user interface

## 🛠️ Technologies Used

* **HTML5** — Structure of the application
* **CSS3** — Styling and responsive layout
* **JavaScript (ES6)** — Functionality and DOM manipulation
